# Student Management System
A desktop application built with Java Swing. Key features include:
- Creating, editing and deleting student records, their modules token, and their grades
- Text-file persistence to save data between sessions
- Student search by their ID for fast lookup
- Exception handling and feedback for invalid inputs  

# How to run
Compile: `javac -cp "lib/jcalendar-1.4.jar" -d out src/*.java`  
Run: `java -cp "out;lib/jcalendar-1.4.jar" Main`
